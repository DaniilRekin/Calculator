# Calculator
Консольное приложение, позволяющее выполнять инженерные и математические вычисления с высокой точностью. Программа поддерживает ввод математических выражений, основные арифметические операции, математические функции и обработку ошибок.

## Основные возможности
- Обращение к стандартным функциям*, константам** и свойствам
  - `sin(pi / 4)`
  - `@ans + 1`
- Динамическое определение сущностей
  - Констант `C = 0.25`
  - Функций `f(x) = x^2 - 5*x`
  - Переменных `$var = pi * 2`
- Удаление сущностей
  - `~C`
  - `~f(x)`
  - `$var`
- Перегрузка функций
  - `f(x)` и `f(x, y)` - это разные функции

### Стандартные атрибуты
#### Локальные атрибуты функций
  @last   последнее глобальное вычисленное функцией значение
  @step   количество вызовов функции
  @min    минимальное значение, которое возвращала функция
  @max    максимальное значение, которое возвращала функция
  @avg    среднее значение от всех вызовов функции
#### Глобальные атрибуты функций
  @last   последнее вычисленное значение
  @ans    последнее вычисленное значение
