# Calculator
Консольное приложение, позволяющее выполнять инженерные и математические вычисления с высокой точностью. Программа должна поддерживает ввод математических выражений, основные арифметические операции, математические функции и обработку ошибок

#### Классы
**Основной класс**
- Calculator
**Исполнительные модули**
- Lexer: разбиение строки на токены
  - Token: описание класса токена
  - Functions: все инженерные функции
  - Constants: все константы
- Parser: по списку токенов строит выражение рекурсивным спуском
- Evaluator: вычисление результата
**Сохранение данных в память**
- Memory: сохранение в память переменных и новых функций
- FileIO: сохранение в файл новосозданных функций и переменных
- History: история вычислений
