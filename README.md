# Calculator
Консольное приложение, позволяющее выполнять инженерные и математические вычисления с высокой точностью. Программа поддерживает ввод математических выражений, основные арифметические операции, математические функции и обработку ошибок.
## Важно
<mark>Описание программы опережает её разработку: файл README.md не в полной мере соответствует настоящим возможностям программы</mark>
## Основные возможности
### Арифметические операторы
- `+`  сложение
- `-`  вычитание
- `*`  умножение
- `/`  деление
- `^`  возведение в степень
### Приоритет операций
> Операции выполняются с учётом их приоритета. Для изменения порядка вычислений используются круглые скобки
- `5 + 2 * 2`    → `9`
- `(5 + 2) * 2`  → `14`
- `2^4`          → `16`
- `5*2^4`        → `80`
- `(5*2)^4`      → `10000`
- `-2^-2`        → `-0.25`
- `(-2)^-2`      → `0.25`
### Обращение к стандартным функциям*, константам** и свойствам***
  - `sin(pi / 4)`
  - `e`
  - `@ans + 1`
## Оперирование сущностями
> Программа позволяет динамически определять константы, функции и переменные.
### Правила именования
Идентификатор сущности должен начинаться с буквы: a-z или A-Z, затем могут продолжаться буквы, цифры и знаки `_`. То есть имя идентификатора должно удовлетворять регулярному выражению `[a-zA-Z]\w*`
### Определение сущностей
- Константы определяются без специального префикса: `C = 10`.
- Переменные начинаются с `$`: `$var = 10`.
- Функции определяются указанием списка аргументов: `f(x) = x^2 - 5*x`. Если функция не принимает аргументов: `g() = $var`.
- Имена стандартных функций и констант нельзя переопределять.
### Вызов функции
- `sin(pi / 4)`
- `f(2)`
- `f(2, 3)`
### Свойства сущностей
| Возможность                                                      | Функции | Константы | Переменные | Свойства / атрибуты |
| ---------------------------------------------------------------- | ------- | --------- | ---------- | ------------------- |
| Можно объявлять                                                  | ✓       | ✓         | ✓          | —                   |
| Можно переопределять значение                                    | —       | —         | ✓          | ✓                   |
| Можно удалить                                                    | ✓       | ✓         | ✓          | —                   |
| Вычисляется при присваивании                                     | —       | —         | ✓          | ✓                   |
| Вычисляется при первом обращении                                 | ✓*      | ✓         | —          | —                   |
| Вычисляется при следующих обращениях                             | ✓       | —         | —          | —                   |
| Можно ссылаться на ещё не существующие сущности при определении  | ✓       | ✓         | —          | —                   |
| Может зависеть от состояния других сущностей в момент вычисления | ✓       | ✓         | ✓          | ✓                   |
#### Отложенное вычисление
>Отложенное вычисление: функции и константы поддерживают ссылки на сущности, которые ещё не существуют в момент их определения. Для констант выражение вычисляется один раз - при первом обращении к константе, таким образом её значение фиксируется. Для функций выражение вычисляется при каждом вызове функции.
##### 1. Определение функций и констант через необъявленные сущности
**Используется A, хотя она ещё не объявлена**
`C = A + 10`
`f(x) = x * A`
**Объявление константы A**
`A = 5`
**Обращение к константе и функции, определённым через A**
`C`                     `15`
`f(2)`               `10`
`f(4)`               `20`
##### 2. Отличие в логике хранения функций и констант
**Значение рассчитывается при каждом вызове:**
`f(x, y) = rand() * (y - x) + x`
`f(2, 5)`          `2.576`
`f(2, 5)`          `4.123`
`f(2, 5)`          `3.739`
**Значение будет подсчитано только единожды:**
`c = rand() * 5` 
`c`                     `4.458`
`c`                     `4.458`
`c`                     `4.458`
### Примеры взаимодействия с сущностями
#### Объявление
  - Констант `C = 0.25`
  - Функций `f(x) = x^2 - 5*x`
  - Переменных `$var = pi * 2`
#### Удаление сущностей
  - `~C`
  - `~f(x)`
  - `$var`
#### Обновление значений
  - `@last = 0`       сброс глобального свойства
  - `f(x):@max = 1.0` сброс локального свойства
  - `$var = -pi`      присвоение значения переменной
## Список стандартных функций, переменных и атрибутов
### Стандартные функции
#### Без аргументов
- `rand()`    случайное число в диапазоне `[0, 1]`
#### С одним аргументом
- `sin(x)`    синус
- `cos(x)`    косинус
- `tan(x)`    тангенс
- `asin(x)`   арксинус
- `acos(x)`   арккосинус
- `arctan(x)` арктангенс
- `sqrt(x)`   квадратный корень
- `abs(x)`    абсолютное значение
- `exp(x)`    экспонента `eˣ`
- `log10(x)`  десятичный логарифм
- `log(x)`    натуральный логарифм
- `ceil(x)`   округление вверх
- `floor(x)`  округление вниз
- `round(x)`  округление до ближайшего целого
#### С двумя аргументами
- `min(a, b)` меньшее из двух значений
- `max(a, b)` большее из двух значений
### Стандартные константы
- `pi`        число π
- `e`         число Эйлера
### Стандартные атрибуты
#### Локальные атрибуты функций
  - `@last`     последнее глобальное вычисленное функцией значение
  - `@step`     количество вызовов функции
  - `@min`      минимальное значение, которое возвращала функция
  - `@max`      максимальное значение, которое возвращала функция
  - `@avg`      среднее значение от всех вызовов функции
  - `@diff_x`   изменение параметра x относительно прошлого вызова функции (доступно для всех параметров функций); для однобуквенных аргументов доступны псевдонимы вида `@dx`
  - `@diff_res` изменение значения функции, относительно прошлого вызова. Для функций с названием в одну букву доступны псевдонимы вида `@df`
#### Глобальные атрибуты функций
  - `@ans`    последнее вычисленное значение
  - `@count`  глобальный счётчик количества вызова рассчётов
