Техническое задание
Проект

Разработка консольного инженерного калькулятора на языке C++

Цель проекта

Разработать консольное приложение, позволяющее выполнять инженерные и математические вычисления с высокой точностью. Программа должна поддерживать ввод математических выражений, основные арифметические операции, математические функции и обработку ошибок.

1. Общие требования
Язык программирования: C++20 (или выше).
Среда выполнения: консоль.
Операционная система: Windows / Linux.
Использование сторонних математических библиотек запрещено (разрешены только стандартные библиотеки C++).
Код должен быть модульным и легко расширяемым.
2. Функциональные требования

Поддерживаются операции:

вычитание (-)

остаток от деления (%)

Примеры:

2^8

3. Нефункциональные требования
Скорость работы

Вычисление выражений до 500 символов должно занимать менее одной секунды.

Надёжность

Программа не должна аварийно завершаться при ошибочном вводе.

Все исключения должны обрабатываться.

Читаемость кода

Использовать

классы
функции
комментарии
понятные имена переменных

8. Требования к тестированию

Проверить:

соблюдение приоритета операций;

9. Критерии приемки

Программа считается выполненной, если:

все заявленные операции работают корректно;
поддерживаются все математические функции из ТЗ;
корректно обрабатываются ошибки ввода;
реализованы история и память вычислений;
отсутствуют утечки памяти;
код успешно компилируется с использованием компилятора C++17 (или выше);
структура проекта соответствует требованиям и код документирован.
